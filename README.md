# Práctica HTML + CSS

Práctica interactiva para estudiar HTML y CSS, basada en la documentación de [MDN Web Docs](https://developer.mozilla.org/es/docs/Web/HTML).

## Cómo usarla

Abre `index.html` en el navegador. No necesita instalación ni internet.

## Qué incluye

- **21 módulos**, de lo básico a lo avanzado:
  - **HTML:** fundamentos, head y metadatos, texto, enlaces, semántica, multimedia, tablas, formularios y accesibilidad.
  - **CSS:** fundamentos, selectores, cascada y especificidad, modelo de caja, unidades, tipografía, fondos y bordes, posicionamiento, Flexbox, Grid, responsive y animaciones.
- **Cada módulo en 4 pasos:**
  1. **Aprende:** conceptos clave y trampas típicas de examen.
  2. **Laboratorio:** editor de HTML y CSS con vista previa en vivo.
  3. **Reto:** ejercicio que se corrige automáticamente.
  4. **Test:** 10 preguntas con explicación.
- **Simulacro de examen:** con cronómetro y nota sobre 5,0.
- **Repaso:** errores guardados, tarjetas de memoria y una chuleta con buscador.

El progreso se guarda en el navegador (`localStorage`).

## Estructura

- `index.html`: página y estilos
- `app.js`: lógica de la práctica
- `contenido/`: módulos (conceptos, ejemplos, retos y preguntas)
